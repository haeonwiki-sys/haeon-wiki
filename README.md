# 해온 위키

해온 봉사단의 헌장, 운영 문서, 봉사 매뉴얼을 모아 둔 위키입니다.
주소만 알면 누구나 볼 수 있고, 고치는 것은 코드를 아는 사람만 할 수 있습니다.

## 문서 구조

| 층 | 문서 | 누가 고칠 수 있나 |
|---|---|---|
| 1층 헌장 | 해온 헌장 | 단장 코드 |
| 2층 운영 문서 | 현재 단장이 하는 일, 공통 절차 | 그 문서 코드 또는 단장 코드 |
| 3층 봉사 매뉴얼 | 공통 매뉴얼 | 단장 코드 |
| 3층 봉사 매뉴얼 | 봉사지 7곳, 희망캔버스 협력 활동 | 그 문서 코드 또는 단장 코드 |

- 위층 문서가 아래층 문서보다 우선합니다.
- 단장 코드로는 모든 문서를 고치고, 모든 코드를 바꿀 수 있습니다.
- 문서 코드와 단장 코드는 관리 화면(`#admin`)에서 단장 코드로만 바꿀 수 있습니다.
- 코드를 바꾸면 이전 코드로 들어와 있던 사람은 바로 막힙니다.

## 위키에 쓰지 않는 것

연락처, 계좌번호, 회원 개인 기록, 사건 기록, 그리고 모든 코드는 위키에 쓰지 않습니다.
이것들은 단장 컴퓨터의 운영 노트(로컬 파일)에 따로 두고 백업합니다.

## 처음 한 번만 하는 설정

1. **설정값 넣기**: `config.js`의 `firebaseConfig`에 파이어베이스 웹 앱 설정값을 넣습니다.
2. **보안 규칙 넣기**: 파이어베이스 콘솔 → Firestore Database → 규칙 탭에 `firestore.rules` 내용을 통째로 붙여 넣고 게시합니다.
3. **첫 단장 코드 만들기**: Firestore Database → 데이터 탭 → 컬렉션 시작
   - 컬렉션 ID: `secrets`
   - 문서 ID: `master`
   - 필드: `code` (유형: string), 값: 단장 코드 (8자 이상)
4. **사이트 켜기**: 깃허브 저장소 → Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 두고 Save.
5. **처음 문서 넣기**: 사이트 주소 뒤에 `#admin`을 붙여 관리 화면으로 가서 구글 로그인 → 단장 코드 입력 → "처음 문서 넣기" → 문서 코드 정하기.

## 코드 관리

- 정한 코드는 운영 노트에 적어 둡니다. 코드는 사이트 화면에 다시 나오지 않습니다.
- 담당자가 바뀌면 그 문서 코드를 바로 바꿉니다.
- 정기적으로(예: 반기마다) 모든 코드를 바꿉니다.
- 단장 코드는 8자 이상, 문서 코드는 4자 이상이어야 합니다.

## 편집

- 문서 위의 "편집"을 누르고 구글 로그인 후 코드를 입력합니다.
- 제목 단계(큰 제목, 작은 제목)만 고르면 1, 1.1 번호는 저장할 때 자동으로 붙습니다.
- "조항 연결"로 다른 문서의 조항을 가리키면, 번호가 바뀌어도 연결이 따라갑니다.
- "확인 필요"로 표시한 칸은 문서 맨 위와 대문에 모입니다.
- 저장할 때마다 이전 판이 남고, "역사"에서 보거나 되돌릴 수 있습니다. 누가 고쳤는지는 구글 계정 이름으로 남습니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 사이트 뼈대 |
| `style.css` | 모양 |
| `app.js` | 보기, 편집, 역사, 관리 화면 |
| `seed.js` | 처음 문서 내용 (처음 문서 넣기, 미리보기 모드에서 사용) |
| `config.js` | 파이어베이스 설정값 |
| `firestore.rules` | 보안 규칙 (파이어베이스 콘솔에 붙여 넣는 원본) |

`config.js`가 비어 있으면 사이트는 미리보기 모드(읽기 전용)로 열립니다.
